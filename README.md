# 🛍️ Kasa Sırası Filozofu

## Bu Ne Lan Böyle?

Sevgili İnsanlık,

Yıllardır marketlerde, bakkallarda, eczanelerde kasa sırasında beklerken içimizden "Hayatın anlamı ne amk?" diye sorduğumuz o anları biliyorsunuz değil mi? İşte o anları bilimsel, felsefi ve tamamen absürt bir şekilde çözmek için yaratıldı **Kasa Sırası Filozofu**.

Bu proje, önünüzde kaç kişi olduğuna göre size özel, derin, anlamsız ve bazen de aşırı ciddi felsefi monologlar üretir. Artık sırada beklerken boş boş telefona bakmak yerine, varoluşsal kriz geçirebilirsiniz. İlerleme kaydedersiniz.

### Nasıl Çalışır?

1. Python 3.x kurulu olsun (değilse üzülün).
2. `python filozof.py` yazın.
3. Önünüzdeki kişi sayısını girin.
4. Felsefe yağmuru başlasın.

### Özellikler

- Tamamen Türkçe ve %100 absürt.
- Gerçekten çalışır (test edildi, kasa sırasında değil).
- Hiçbir şekilde faydalı değil ama hissettirir.
- Patatesle alakası yoktur. Yemin ederim.

### Uyarı

Bu kodu çalıştırırken kasa görevlisi size "Abi ne gülüyorsun?" diye sorabilir. Sorumluluk kabul etmiyoruz.
